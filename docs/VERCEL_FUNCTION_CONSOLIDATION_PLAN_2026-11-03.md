# Consolidação das funções Vercel — branch de revisão, 03/11/2026

Conforme documentação da Vercel, arquivos dentro de `api/` viram funções individuais. O projeto excedia o limite de 12 funções no plano Hobby e falhava após build. Nesta branch, 15 endpoints INEA foram movidos sem modificar seu conteúdo para `server/air/inea`, com helper `_http`; sete endpoints de compartilhamento foram movidos para `server/share`, com helper `_html`. Dois roteadores de lista branca (`api/inea-router.ts` e `api/share-router.ts`) preservam as URLs públicas através de rewrites explícitos. As sete URLs `/s/...` são direcionadas diretamente ao roteador de compartilhamento para não depender de rewrites encadeados. Os scripts de diagnóstico e smoke passam a importar os handlers internos. Teste estático incluído em `npm run vercel:functions:imports` e validado em CI. Nenhuma chave é exposta. Não mesclar sem teste de deploy preview, acessibilidade, API INEA e links OG.
